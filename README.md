# Istanbul Real Estate Data Analysis

**Status: Work in Progress**

## Project Overview

This project focuses on analyzing the Istanbul residential real estate market using data analysis and machine learning techniques.

The main objective is to explore apartment characteristics, identify factors influencing property prices, and discover patterns and segments within the real estate market.

## Project Objectives

- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Analyze property prices and price per square meter.
- Identify relationships between apartment characteristics and prices.
- Apply classification and clustering algorithms.
- Evaluate and interpret model results.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
